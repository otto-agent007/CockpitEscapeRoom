# Correcting character art in the gym

Open `/dev/gym.html`, choose Captain's jab or heavy in **Clip**, and scroll to **Art corrections**. Keep **idle · anchor** as the fixed reference to compare both moves to the same Captain.

1. Choose **Whole clip** to fix every drawing, or **Current drawing** for an individual correction. Reused poses with the same drawing path share that drawing's edit.
2. Use **Match reference height**, then **Align body and feet to reference**. Height scales around the grounded feet. Alignment uses the torso rather than an extended hand/cup; it also keeps feet within the existing pivot tolerance. The readout shows height, body difference, baseline and foot center. A remaining body difference may require a manual nudge or source-art refinement.
3. Select **Shoes**, **Hat** or **Trousers**, then **Match area palette to reference**. Repeat for each part. The yellow rectangle limits changes; adjust its x/y/width/height to protect trim, skin and accessories. Lower color tolerance protects colors farther from the reference. If lighter gray or bright shoe areas remain unchanged, enable **Match all colors in selected area** and apply again: this maps every visible pixel in the rectangle to a reference color regardless of tolerance. The status reports changed pixels and tolerance skips. Repeating a match with no changes leaves the draft and Undo history intact. The reference palette keeps multiple shading colors; it is not a forced single-color fill, though brighter shades can converge to the nearest reference shade.
4. For a specific color, click the current drawing to sample the source and the reference to sample the target. Native **Sample x/y** fields and **Sample source/reference** buttons provide the same operation by keyboard. Apply **Color replacement** with or without preserving shade differences.
5. Use normal frame controls, Play, mirror and onion skin to inspect the clip. **Show original during playback** compares the untouched source. **Overlay reference on stage** exposes drift. Source-sampling views stay right-facing even when the stage is mirrored.
6. **Undo art** reverses a recipe step; **Reset chosen scope** restores originals for that scope. Draft recipes survive reload in this tab. Change clips to apply the same fixed reference to the jab and heavy; drafts on the other clip stay available.
7. **Save corrected copy** runs the existing sprite gate and creates a new unbound, unreviewed clip. Original clips/PNGs remain intact. New PNGs and `recipe.json`/`gate.txt` live under `art-source/arcade/<fighter>/gym-edits/<id>/`. The recipe records original/output hashes and the fixed reference. Existing timing/box **Save** is separate; it cannot silently save preview-only art. A corrected copy uses the saved original clip's timing, leaving other unsaved timing/box edits local.

Save refuses clipping, missing/changed source or reference art, stale table state and sprite-gate errors. The valid draft remains available for correction/retry. Grounded sprites must keep baseline 119 and foot pivot 64 within 1px; specialized walk/airborne normalization remains in the source pipeline. Nearest-pixel height correction can change small details, so inspect it before adoption. These tools correct color/geometry placement; they do not redraw inconsistent anatomy.

All editing is local; no image service or production dependency is required. Exact PNG decoding preserves translucent RGB values before corrections, so the exported copy matches the preview. Pose acceptance, box authoring/sign-off and combat wiring still follow `.agents/skills/arcade-animation/SKILL.md`.
